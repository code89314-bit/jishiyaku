# 医薬品マスターの置き場所

このフォルダにファイルをアップロードすると、GitHub Actions が自動で `master.json` を作ります。
アプリは開いたときに新しい版を確認し、あれば自動で取得します。

置けるファイル（.xlsx .xls .csv .txt .tsv .zip）
- 厚生労働省「薬価基準収載品目リスト」（Excel）… 薬品名・薬価基準収載医薬品コード・成分名・規格・先発/後発
- MEDIS「医薬品HOTコードマスター」… 販売名・YJコード・HOTコード・JAN
- GS1コード（販売包装単位・調剤包装単位）の対応表 … HOTコードで薬品名と結びつけます

古いファイルは削除するか、新しいファイルで上書きしてください（フォルダ内のファイルをすべて合わせて作ります）。
