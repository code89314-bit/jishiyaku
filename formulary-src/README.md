# 採用薬リスト（棚表）の置き場所

このフォルダに院内の採用薬リスト（棚表）の Excel / CSV を置くと、GitHub Actions が
医薬品マスターと照合して `formulary.json` を作ります。アプリは代替薬の判定にこれを使います。

- 薬品名の列は自動で見つけます（規格が別の列にあれば、それも合わせて読みます）
- 誤字脱字・略記はあいまい一致で吸収します。規格の数字（5mg と 2.5mg など）は厳しく見ます
- 照合が怪しい行は、アプリの「採用薬リストの確認」で候補から選んで直せます
- 直した内容は `formulary-fixes.csv`（棚表の表記, YJコード）に記録され、次回から使われます
